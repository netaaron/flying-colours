Language and culture final report

開南大學應用英語學系「語言與文化」課堂報告的網頁版（原簡報：16 頁 PowerPoint）。
報告人：李青勇、梁家綺

## 頁面結構

封面 → 目錄 → 七章（C・O・L・O・U・R・S）→ 間奏「片語家族地圖」→ 終章「語言化石」→ 期末考 → 參考資料

每讀到一章，頁面頂端的桅繩就升起一面國際信號旗；七章讀完，正好拼出 COLOURS。期末考答對八題以上，所有旗子一起飄揚。

## 互動小遊戲

| 位置 | 名稱 | 玩法 |
|---|---|---|
| 第一章 | 翻字卡 | 點 colours，翻出 flags |
| 第一章 | 旗語站 | 輸入英文字，掛成信號旗；點旗看單旗意義（NC＝求救） |
| 第三章 | 語意時光機 | 拖時間軸：come off with flying colours → pass with flying colours |
| 第四章 | 說法鑑定所 | 五則說法，判斷「有文獻撐腰」或「好聽但靠不住」 |
| 第五章 | 釘旗挑戰 | 指針進金色區時按「釘！」／空白鍵，釘滿四根獲勝 |
| 第六章 | 降旗劇場 | strike／lower／go down with colours flying 三種旗子動畫 |
| 期末考 | 十題填空 | 8 題以上 Passed with flying colours!（彩旗慶祝） |

## 其他

- 字型取自 Google Fonts（Libre Caslon、Noto Serif TC、Noto Sans TC）；離線時自動改用系統字型，功能不受影響。
- 信號旗依《國際信號規則》（International Code of Signals）以 SVG 繪製，不需要圖檔。
- 歷史場景圖為 AI 生成的情境示意圖，並非史料照片。
- 不需任何安裝或建置；所有程式碼都在 `index.html` 內。
