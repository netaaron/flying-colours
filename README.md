# With Flying Colours｜一個片語的歷史

Language and culture final report

開南大學應用英語學系「語言與文化」課堂報告的網頁版（原簡報：16 頁 PowerPoint）。
報告人：李青勇、梁家綺

## 檔案

```
index.html      整個網頁（版面、文字、小遊戲都在這一個檔案裡）
images/         13 張情境圖（WebP）＋ 分享縮圖 og-cover.jpg
README.md       本說明
```

## 網址

https://netaaron.github.io/flying-colours/

## 頁面結構

封面 → 七章（C・O・L・O・U・R・S）＋ 間奏「片語家族地圖」→ 終章「語言化石」→ 小遊戲 → 參考資料

正文全部是靜態圖文，方便 3 分鐘內講完；每讀到一章，頁面頂端的桅繩就升起一面國際信號旗，七章讀完正好拼出 COLOURS。

## 小遊戲（都在最後）

| 名稱 | 玩法 |
|---|---|
| 說法鑑定所 | 五則說法，按「有憑有據」或「以訛傳訛」 |
| 釘旗挑戰 | 指針進金色區時按「釘！」／空白鍵，釘滿四根獲勝；成功後頂端旗子全部升起、彩旗飄落 |

## 上台報告時

- 鍵盤 **← →** 逐節翻頁（封面、各章、終章、小遊戲、參考資料）。
- 小遊戲區右上角的「音效」可關閉遊戲音效。
- 系統設定為「減少動態效果」時，動畫會自動關閉。

## 其他

- 字型取自 Google Fonts（Libre Caslon、Noto Serif TC、Noto Sans TC）；離線時自動改用系統字型，功能不受影響。
- 信號旗依《國際信號規則》（International Code of Signals）以 SVG 繪製，不需要圖檔。
- 歷史場景圖為 AI 生成的情境示意圖，並非史料照片。
- 不需任何安裝或建置；所有程式碼都在 `index.html` 內。
